# 🌙 Portafolio Personal — Jardín Nocturno

Portafolio interactivo temático "Jardín Nocturno" desarrollado como Full-Stack | Base de datos. Combina Canvas 2D animado, Web Audio API, navegación por teclas de piano y diseño responsive con paleta inspirada en la alta costura y la botánica nocturna.

## ✨ Características

- **Canvas 2D animado**: Colibrí luminoso, mariposas, destellos y estaciones florales interactivas
- **Web Audio API**: Notas musicales asociadas a cada sección y tarjeta de habilidad
- **Controles de sonido**: Activar/desactivar audio ambiental en el HUD
- **Navegación por piano**: Teclas interactivas en la parte inferior para saltar entre secciones
- **Diseño responsive**: Adaptable a escritorio y móvil
- **Imagen de perfil**: Foto personal en las secciones "Sobre mí" y "Contacto"
- **Formulario de contacto**: Buzón para consultas de proyectos y colaboraciones

## 📁 Estructura

```
index.html        — Punto de entrada y estructura principal
styles.css        — Estilos y paleta visual (oro rosa, medianoche, terciopelo)
main.js           — Orquestación de audio, modal y navegación
sections.js       — Contenido de cada sección (Sobre mí, Habilidades, etc.)
garden.js         — Mundo del jardín: colibrí, mariposas, estaciones, destellos
audio.js          — Síntesis de audio con Web Audio API y reverb
```

## 🚀 Uso

Abre `index.html` en un navegador moderno. Haz clic en la flor de cristal para abrir el telón, luego usa las teclas del piano inferior o haz clic en las estaciones del jardín para explorar cada sección.
